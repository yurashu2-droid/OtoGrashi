# 原声保持版に対するMADパフォーマンス拡張

基準コミット: d7608e334d96aec8075d8e91a008d8d5b82a469d。
回収した演出実装: e7681d6f19d61241abd54c17d54a98319643dd6c。

## 方針
承認された自然モードのDSP、音声区間の連続性、声域ヒント、MIDIの音価を維持する。7案は選択式の追加モードとして統合する。原声の意味理解・自動文字起こしは行わない。

## 実装・検証手順
1. 自然モード5種類の原声イベントをd7608e3から固定し、回収版の4種類で差異を再現する。
2. 回収版で失われたregisterMidiNoteと音価付きpitchSteps、連続した発話位置を復元する。
3. 7モード×15/30秒×1〜6素材の音/動画契約、素材範囲、音価を検証する。
4. 語頭連打・原声・同じ発話の語尾エコー、レコード往復、表示の整合を修正する。
5. 適用パッチをクリーンな基準版に当て直し、ファイルハッシュと同一の検証結果を確認する。
6. 成果物にパッチ、変更済みコード、適用スクリプト、検証記録を含める。

## 今回の追加修正
- d7608e3で承認された自然モード5種類のイベント列を固定し、完全一致を回帰検証する。
- 語尾エコーは「いま再生したフレーズの末尾」から取る。元動画のもっと後の部分は使わない。
- 音量表示はミックス全体ではなく各イベントの実PCM・ゲイン・フェードから算出する。
- MIDIの休符・音価とキャッシュ識別を維持する。音符の境界で映像を巻き戻さない。
- 極端な声域、短い素材、逆再生、30秒の境界を検証。生成音のピッチ変更と動画の反復時計は共有。
- IPA作成補助はmacOSでのみ実行し、ソースZIPにも対応。実際にビルドした主要コードのハッシュを添付する。

## 誇張しないための境界
字幕・単語の意味を認識した語尾抽出ではなく、波形範囲の先頭と末尾の編集。
スクラッチは音声・映像の前後編集とピッチ曲線で、自由な速度変化のDJエンジンではない。
円形表示は各イベントの音量包絡で、FFT周波数スペクトルではない。
追加演出のネイティブMP4書き出しとFlutter UI全体の試験は実行用テストを同梱するが、このパッチ作成環境では未実行。

# 原声を残すMADパフォーマンス

## 目的
会話と生活音の原型を残した従来の自然モードを維持し、音と映像が同じ素材区間で動く追加演出を選択できるようにする。ユーザーが実装・GitHub反映・無署名IPA作成を明示的に許可した拡張。

## 実装するモード
- natural: 既存の地続きの声処理。15秒の従来動作は保存。
- mosaic: 左上から使用した素材/区間を追加。先頭連打→原声→語尾エコー。
- vinyl: 円形ディスク、素材時計による回転、音声と映像の前進/逆再生とピッチ曲線のスクラッチ風アクセント。
- sampler: 固定パッド、活動中の色枠/弾み/円形音反応表示。
- voiceLead: 同じメロディ素材を反復し、長めの原声を手前に。伴奏を弱める。
- neonTune: このモードだけ急な音程遷移と色相/渦エフェクト。
- loopStation: 4つ打ち→低音→地続きメロディ→原声。表示も順次追加。

## 時計と素材
15秒=720000、30秒=1440000サンプル、48kHz、30fps。30秒は第2セクションで密度/モチーフが変わる。音/映像にpartIndexを共有し、1〜2素材なら同じ録音の別の可聴区間や前後の部分を使う。原声は可聴範囲を越えず、楽器化した長音のみ同期ループ可能。リズムだけ指定は全モードでピッチなし。

## 検証と制約
Flutter選択UI/保存復元、56通りの時計/素材境界、Swift原声回帰、実Dart→Swiftの各モードMP4書き出し、30秒の本番MediaValidatorを確認する。最終IPAはdevice arm64 Release、署名/Teamなし。セリフの意味や日本語音節を認識しているわけではなく、波形区間の先頭/末尾を切る。スクラッチは速度可変DJエンジンではなく前後の編集。円形表示はミックス音量への反応で、個別音源のFFTではない。実機の音質判断は別。

# 提供された3パートMIDIを日常音で演奏する

## 目的

提供された `score_image_3part_transcription.mid` の旋律・低音・ピアノの発音位置と音程を、録った動画付き音に割り当てる。楽器音源の伴奏は足さず、完成動画の音と映像が同じイベントで変わる体験を守る。既存の自動曲テンプレートは残す。

## 入力の確認

- SHA-256: `F1F87A116E70D1A00296F56DEEAB78D8066FD0DF76A2318425E44B5766EF88ED`
- Format 1、480 ticks/beat、4/4、152 BPM、B♭、約37.9秒。
- Melody / Bass / Piano の3トラック。最初の8小節にそれぞれ76 / 32 / 40音、計148音がある。
- アプリは15秒、128 BPM、8小節の固定時計を持つ。このテンプレートはMIDI冒頭8小節の相対的な発音位置と長さを128 BPMで再生し、ちょうど15秒にする。原曲全体の再生や任意のMIDIファイル取り込みはこの実装の対象外。

## 体験

素材を3〜6本集め、「3パート楽譜」を選ぶと、解析から旋律・低音・ピアノ役を提案する。どの素材がどの役か画面で明示する。録った音だけで曲を作り、MIDIの休符・重なり・音価を反映する。完成映像のカットや増殖は、実際に鳴る音イベントと同じ時刻を使う。

音程が安定して測れる素材はMIDIの目標音へ移調する。曲全体を素材の声域へ移し、低音・ピアノは必要ならオクターブ単位で寄せて和声を保つ。音程が測れない打音・雑音はMIDIの発音時刻に置くが、音程が合ったと偽らない。実際に鳴る長さは素材の可聴区間を超えない。使用できない無音素材は既存のエラー・再撮影導線へ返す。

## 実装の境界と品質

現在の音声／映像契約は64イベント、音程変更±3半音。148音の楽譜を名前だけのテンプレートにしないため、契約を必要な範囲で拡げ、繰り返し使う素材・音程の処理を再利用して待ち時間を抑える。既存テンプレートのイベント数と±3半音の選択規則は維持する。MIDI専用テンプレートの音程変更は品質上限を設け、実機で聴いて不自然なら役・移調・使用音域を調整する。

MIDIファイルをリポジトリに保持し、そこから決定的に生成したトラックデータをアプリで使う。変換後の音数、時刻、音高、音価をテストで照合する。DartとSwiftの契約上限、3〜6素材、保存・再編集、音声／映像の開始一致を対象に確認する。フルビルドは変更がまとまってから一度行う。

# バックグラウンドでの動画作成

対象: 初回プレビュー、作り直し、高画質書き出し。音楽・映像の生成内容は変更しない。

- 音声処理・映像処理・検証が完了するまで UIKit の background task を確保し、成功・失敗・時間切れで一度だけ解放する。
- `willResignActive` で処理中の GPU 描画を終えてから CPU 描画へ切り替える。復帰すると GPU 描画を使う。ステッカー切り抜きも背景では CPU を使用し、端末が対応しない場合は復帰後に生成し直す。前景での切り抜きは従来のアクセラレーターを使用する。
- 時間切れでは、その生成試行だけを中止する。作成要求と排他所有権を保持し、復帰時に同じ素材・設定・seed で最初から生成し直す。途中のフレームからの再開ではない。
- ユーザーのキャンセルは親トークンから全試行へ伝わり、自動再作成を止める。
- 素材と書き出し先を `completeUntilFirstUserAuthentication` で保護し、画面ロック中の読み書きを許可する。
- 背景で完成しても共有画面・初回の写真許可ダイアログは復帰まで待つ。
- バックグラウンド実行時間は iOS が決める。強制終了や OS によるプロセス終了後の自動再開は対象外。無音再生などによる実行時間の延長は行わない。

検証: ローカルの作成フロー・キャンセル関連の既存 Flutter テスト。`[background-render]` の CI では Simulator ビルドと関連 XCTest のみを実行し、期限切れ・二重解放・キャンセルの分離・CPU 描画の色・15 秒動画の映像音声を確認する。実機での OS 停止タイミングは Simulator のテストだけでは確認できない。

実機確認: 作成直後にホームへ移動 / 画面をロック / 長く離れてから復帰 / 復帰後にキャンセル / 高画質書き出し中に離れてからシェア画面を開く。

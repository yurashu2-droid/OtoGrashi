オトグラシ（以下「本アプリ」）は、身の回りの音や声を短く撮って、曲と動画にするアプリです。本アプリが扱う情報と、その使い方を説明します。

## 1. 端末の中だけで扱う情報

次の情報は、あなたの iPhone の中だけで保存・処理します。運営者のサーバーには送りません。

- **カメラ・マイクで撮った動画と音**：曲づくりのために使います。撮った音の分析（音の高さや区切りの検出）、曲づくり、動画の書き出しはすべて端末の中で行います。
- **写真から取り込んだ動画**：あなたが選んだものだけを取り込みます。
- **つくった曲・作品、音の名前、フォルダ、タグ、読み込んだ MIDI の曲**
- **動画の表紙に入れるあなたの名前**（設定で入力した場合）
- **「この人の曲を表示しない」にした相手**（相手を見分けるための記号と、表示名）

完成した動画を写真アプリに保存するときは、写真ライブラリへの追加の許可を求めます。保存とシェアは、あなたが操作したときだけ行います。

## 2. サーバーに送る情報（共有機能を使うときだけ）

次の機能を使ったときだけ、運営者のサーバー（Cloudflare 上で運用）に情報を送ります。使わなければ送りません。

| 機能 | 送る・保存する情報 |
| --- | --- |
| アカウント（パスキーでログイン） | 表示名、パスキーの公開鍵（端末の生体認証の情報やパスキーの秘密鍵は送りません）、ログイン中であることを示す情報（30日で失効） |
| 共有フォルダ（「友だちと音を集める」） | あなたが共有を選んだ動画と音、そのサムネイル、音の名前と長さ、フォルダ名、メンバーの表示名 |
| みんなの曲（曲の投稿） | 投稿した曲の楽譜（音の高さと長さの並び。録音した音は含みません）、曲名、作者・出典、権利についてのあなたの申告、投稿時の表示名、使われた回数 |
| 通報 | 通報の理由と、任意で書いた説明 |

共有フォルダに入れた動画と音は、そのフォルダに参加している友だちが見たり、自分の端末に保存したりできます。みんなの曲に投稿した曲は、だれでも見て使えます。

### 不正利用の防止のために扱う情報

- 短い時間に大量の操作が来ないように、接続元の IP アドレスを**ハッシュ値（元に戻しにくい形）**にして一時的に使います。
- 曲が使われた回数を数えるために、このハッシュ値・曲・日付の組を記録し、**2日後に削除**します。

## 3. 外部のサービス

- **Cloudflare**：共有フォルダ、アカウント、みんなの曲のサーバーとデータの保存に使います。
- **Hugging Face**：「とびだす」を追加するときに、3D 化に使うモデル（Apple が公開している Depth Anything V2、約50MB）を一度だけダウンロードします。このとき通常のダウンロードと同じく、接続元の IP アドレスなどがダウンロード元に届きます。撮った動画は送りません。

本アプリには広告、行動の追跡（トラッキング）、利用状況の分析ツールは入っていません。

## 4. 保存する期間と削除

- 端末の中の情報は、アプリの中で削除するか、アプリを削除すると消えます。
- 共有フォルダの音は、入れた人またはフォルダをつくった人が削除できます。フォルダを閉じると、中の音もすべて削除します。
- 投稿した曲は、いつでも「自分の投稿をみる」から取り下げられます。
- **アカウントの削除**：設定または「友だちと音を集める」画面から、いつでもアカウントを削除できます。削除すると、次の情報をサーバーから削除します。
  - アカウント、パスキーの公開鍵、ログイン情報
  - あなたがつくった共有フォルダ（中の音も含む）
  - 参加していたフォルダへの参加と、そこにあなたが入れた音
  - あなたが投稿した曲、あなたがした通報

  端末の中の音や作品は残ります。

  ※ 削除の前に自分で退出したフォルダに入れた音は、アカウントとのつながりが残っていないため、アカウントの削除では消えません。退出する前に音を削除するか、お問い合わせください。

## 5. 第三者への提供

法令に基づく場合を除き、あなたの情報を第三者に売ったり、提供したりしません。

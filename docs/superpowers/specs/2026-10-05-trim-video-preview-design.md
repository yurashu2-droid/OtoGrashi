# 音の範囲と映像を同時に確認する

目的は、どの場面の音を曲に使うのかを範囲選択中に理解できること。

- 共通の範囲選択シートに、元の動画のプレビューを波形の上へ置く。
- 開始・終了のつまみを動かすと、その位置の映像へ移動する。連続操作は最後の位置を優先し、古い seek をためない。
- 選んだ範囲は同じプレビューで映像・音を再生し、現在位置を波形と時刻で示す。別の再生ポップアップを開かない。
- プレビューは動画全体を保持し、つまみ操作でネイティブビューを作り直さない。元動画を切り取らず収めて表示する。
- 作成画面・音のストック・簡単調整の範囲選択を共通化する。保存は明示的な確定時に行う。
- 読み込み・再生エラーを画面内に示し、閉じた後やバックグラウンドで音を鳴らし続けない。
- 既存の選択範囲の保存形式と最大6秒を維持する。新しい書き出しはプレビュー時に生成しない。

Cloudflare の別作業では既存の非公開R2・パスキー共有仕様を維持する。公開入口を main に置き、source_ref で現在の開発コードを取得する。資格情報は GitHub Secrets にのみ登録し、未登録時は公開せず明確に止める。

# 友だちとの共有フォルダ

ホームの「みんなの音」から開きます。選んだ素材だけを共有し、友だちが
追加した音を試聴・ストックに保存・曲づくりに使えます。曲と動画の生成は
これまでどおりiPhoneの中で行います。

## 最初のCloudflare設定（運営者が一度だけ行う）

この変更にはサーバーのコードを含みます。Cloudflareへの配置は別途必要です。
R2だけでなく、アクセスを管理するWorkerと、フォルダ情報を保存するSQLite
Durable Objectも同じCloudflareアカウントに作成します。

1. CloudflareでR2を有効にし、`otograshi-shared-folders-private`という
   バケットを作成します。公開用の`r2.dev`やバケットの公開ドメインは無効のままにします。
2. `backend/shared-folders/wrangler.jsonc`のWorker名・バケット名を確認します。
   既存バケットを使う場合は`bucket_name`を変更します。レート制限の
   `namespace_id`は、アカウント内の別Workerと重ならない番号にします。
3. Node.js 22.15以上の環境で、リポジトリ内の`backend/shared-folders`へ移動し、
   次を実行します。ブラウザで目的のCloudflareアカウントへログインします。

   ```powershell
   npm ci
   npx wrangler login
   npx wrangler whoami
   npx wrangler deploy
   ```

   Durable Objectは設定済みのマイグレーションで作成されます。
   APIトークンやR2の秘密鍵をアプリ・リポジトリへ入れる必要はありません。
4. 表示されたHTTPSのWorker URLを控えます。
   例：`https://otograshi-shared-folders.<サブドメイン>.workers.dev`
5. アプリの「みんなの音」→「共有フォルダをつくる」で、未設定時に表示される
   「サービスのアドレス」へそのURLを入力します。URL設定のためのIPA再生成は不要です。

## 友だちと使う

1. フォルダ名と友だちに見える表示名を入力し、フォルダをつくります。
2. 右上のメニューから「招待リンクを発行・更新」を開き、リンクをコピーして送ります。
3. 友だちはリンクからアプリを開くか、「招待リンクで参加する」に貼り付けます。
   接続先を確認して表示名を入れ、「この接続先に参加する」を押します。
4. 「自分のストックから共有」で素材を選びます。全ストックが自動送信されることはありません。
5. 下へ引っぱって更新し、友だちの素材を試聴・保存します。
   チェックした最大6つの素材から、既存の曲づくり画面へ進めます。

招待リンクの期限は7日です。再発行すると以前のリンクは無効になりますが、
参加済みの友だちはそのままです。作成者は参加者のアクセスを取り消せます。
素材を追加した人と作成者は共有側の素材を削除できます。
共有から削除・退出しても、端末に保存した素材や作品は残ります。

## 現在の範囲

- 1素材50MiBまで、1フォルダ1GiB・200素材・20人まで。動画は180秒以内です。
- 招待された人が利用する非公開フォルダです。アカウント作成や共同編集はありません。
- 参加情報は端末に保存します。別の端末では招待から参加し直します。
  作成者の端末の再インストール・参加情報の消去に対するアカウント復旧は未対応です。
- 現時点でCloudflareへの本番配置と2台のiPhoneによる往復確認は未実施です。

詳細なサーバー設定と検証方法は[バックエンドREADME](../backend/shared-folders/README.md)を参照してください。

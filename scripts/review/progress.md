# Everyday MAD implementation review

Baseline: `099eccfddf44636334e84564e5944aba631bb3f7` (`codex/midi-score`). Changes are isolated in `codex/everyday-mad-overhaul`, PR #1. Temporary source-delivery workflows have been removed from the product tree.

## Implemented

- Region-specific, interpolated pitch estimation; silence padding no longer prevents sustained pitch analysis.
- Source-derived periodic resynthesis for changing voices and noise, natural phrase spotlights, sustained notes, source-window loops, real overlapping echoes and reverse pickups.
- Shared source duration/reverse clock for audio and video; audible-source panels, mirror cuts, beat punches and duplicate panels corresponding to simultaneous voices.
- Serialized player commands, stale-view cancellation, trim-aware native view identity, portrait composition transforms, and thumbnail decode fallbacks.
- Existing serialized events retain their legacy defaults. The new musical arranger is used for new song templates.

## Verification evidence

- Actual portable Swift DSP regression: 40 checks passed; nine tested fundamentals from 60 to 1760 Hz stayed within 8 cents. Tone/glide/noise retuning preserved length and reached tested target notes.
- Actual extracted analyzer regression: silence-padded 220 Hz stays tonal; separate 220/330 Hz regions keep independent pitches without assigning one pitch to the whole recording.
- Swift source syntax check passed; this is not an iOS API type-check.
- Linux CI on `df4a67d3`: `flutter analyze --fatal-infos` reported no issues; 148 Flutter tests passed, one skipped, one stale legacy-role expectation failed. That final expectation was corrected in `2eff5a89308aea713c038a50604e0b8c409ecdfb`; full validation is being rerun.
- Cross-language fixture generated by the actual Dart arranger: 117 sound events, 85 tuned notes, three natural phrases, 59 mirrored video events, 171 video scenes. Native CI includes rendering this fixture to a real 15-second MP4 rather than validating only a hand-written payload.

Final CI outcomes and downloadable render evidence are recorded in PR #1. Real-device visual alignment and the subjective intelligibility/fun of representative friends' speech remain distinct from synthetic regression tests. This review does not claim every possible application bug has been eliminated.

# パブリックドメイン曲 MIDI テンプレート

オトグラシで録った音を、メロディ・和音・ベース・リズムへ割り当てるための短いMIDIです。
各ファイルは約15秒、Standard MIDI File Type 1、480 ticks/beatです。

## トラック構成

1. `Melody` — チャンネル1
2. `Chords` — チャンネル2
3. `Bass` — チャンネル3
4. `Rhythm` — チャンネル10（General MIDI percussion）

## 収録曲

- 歓喜の歌 — ベートーヴェン
- きらきら星 — 18世紀フランスの伝承旋律
- エリーゼのために — ベートーヴェン
- ジングルベル — ジェームズ・ロード・ピアポント
- 運命の動機 — ベートーヴェン「交響曲第5番」冒頭動機の短い展開
- パッヘルベルのカノン — 定番の低音進行を使った短い展開

いずれも作曲・原旋律の保護期間が終了している作品です。このフォルダのMIDIは、既存の演奏録音や市販MIDIを変換したものではなく、オトグラシ向けに新しく打ち込んだ簡易編曲です。現代の編曲・演奏・録音には別の権利が生じるため、それらは素材として使用していません。

再生成:

```powershell
python tool/generate_public_domain_midis.py
```

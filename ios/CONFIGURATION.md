# iOS configuration

The generated `com.example.otogurashi` bundle identifier is a provisional
identifier for unsigned Simulator builds only. It must be replaced with the
real App Store Connect bundle identifier and Apple team configuration before
creating an archive or uploading a build. Do not ship or upload using the
placeholder identifier.

The project targets iOS 18.0 and uses the generated Swift application
delegate, scene delegate, and shared `Runner` scheme.
